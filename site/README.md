# K4 Provisions LLC website

A static site: plain HTML, CSS and JavaScript. Upload the `site` folder to any static host (Netlify, Cloudflare Pages, GitHub Pages). `404.html` is picked up automatically by Netlify and Cloudflare Pages.

## Pages
| File | Page |
|---|---|
| `index.html` | Home, with the 3D hood cleaning scroll animation |
| `hood-cleaning.html` | Kitchen hood and exhaust cleaning |
| `parking-lot-cleaning.html` | Parking lot pressure washing |
| `garbage-can-cleaning.html` | Garbage can and dumpster pad cleaning |
| `service-area.html` | About K4 and the North Texas cities served |
| `contact.html` | Quote form, phone, text and email |

## Editing pages
The pages are generated so the header and footer stay identical everywhere.
1. Edit the page content in `_build/pages/` (or the shared header/footer in `_build/layout.html`).
2. Run `python3 site/_build/build.py` to regenerate the HTML in `site/`.

Phone number and email live at the top of `_build/build.py`.

## Quote form
Requests are emailed to k4provisions@gmail.com through FormSubmit (formsubmit.co, free).
**The first time someone submits the form, FormSubmit sends an activation email to that inbox. Click the link once** and every request after that arrives as a normal email. The endpoint is set at the top of `assets/js/site.js`.

## Before/after images
The sliders use illustrations in `assets/img/ba/` (generated by `_build/illustrations.py`). When you have real job photos:
1. Save them as e.g. `assets/img/ba/hood-before.jpg` and `hood-after.jpg`, taken from the same spot and cropped to the same size (about 3:2).
2. In the page under `_build/pages/`, change the two `src` values (and the `alt` text) in that slider, delete "Illustration of a typical result." from the caption, and rebuild.

## The 3D animation
`assets/js/hood-scene.js` builds the hood, filters, duct and rooftop fan with Three.js (bundled locally). It loads after the page appears, uses a lighter version on phones, pauses off screen, respects "reduce motion", and falls back to a still image without WebGL. Add `?still` to the URL to render only while scrolling (for screenshots).
